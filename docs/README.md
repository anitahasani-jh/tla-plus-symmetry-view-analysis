## مسیر ۲ — «می‌خواهم پروژه را داوری/نمره‌دهی کنم» (۲ ساعت)

۱. `report_fa.md` — گزارش کامل، ۱۳ بخش + ۴ پیوست
۲. `soundness_report_fa.md` — برهان سلامت و محدودیت‌ها
۳. `tools_verification.md` — بررسی ابزارها و مقالات (بند ۱-۱ راهنما)

۱. `راهنمای-استفاده.md` — نصب، اجرا، تور مخزن، عیب‌یابی

۳. `../src/symview/pipeline.py` → `context.py` → `analysis/symmetry.py` → `analysis/history.py` → `codegen.py`

## کدام سند «منبع حقیقت» است؟

| پرسش | سند مرجع |
|---|---|
| یک عدد مشخص (مثلاً میانهٔ کاهش) | `analysis/output/numbers.json` |
| جدول کامل یک سؤال پژوهشی | `analysis/output/tables/rq*.md` |
| تعریف روش و الگوریتم | `report_fa.md` بخش ۴ + `soundness_report_fa.md` |
| وضعیت نسخهٔ ابزار و محیط | `results/raw/environment.json`، `config/tools.yaml` |
| commit گزارش‌شده | `results/raw/git.json` |
| نقص‌های پیدا و رفع‌شده | `results/raw/findings.json` |

> اگر عددی در متن با جدول نخواند، یعنی `python analysis/make_report.py` دوباره اجرا نشده است. متن گزارش **تولیدشده** است، دستی ویرایش نمی‌شود.
